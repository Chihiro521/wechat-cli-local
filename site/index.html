GET STARTED

从安装到第一条查询

在 Windows x64 的 PowerShell 中完成。

01

准备 Node.js

需要 Node.js 22 或更新版本。先检查本机版本：

node --version
npm --version

首次安装 Node.js？前往 Node.js 官网下载 LTS 版本 ↗，安装后重新打开 PowerShell。

02

安装并确认 CLI

npm 会安装启动器和 Windows 独立程序。

npm install -g wechat-cli-local
wechat-cli --version
wechat-cli --help

npm 包名是 wechat-cli-local。安装后，wechat-cli 和 wechat-cli-local 两个命令都可以使用。

03

初始化，开始查询

先启动并登录本机微信，再初始化数据目录和读取配置。需要进程读取权限时，可在管理员 PowerShell 中执行。

wechat-cli init
wechat-cli sessions --limit 10

初始化后，配置保存在用户目录 ~/.wechat-cli/。查询默认输出 JSON，方便后续处理。

EVERYDAY COMMANDS

装好之后，可以这样用

全部命令与参数 ↗
联系人

找到想聊的人

wechat-cli contacts --query "张三"
聊天记录

查看最近的消息

wechat-cli history "示例群" --limit 50
搜索

从聊天里找关键词

wechat-cli search "关键词" --chat "示例群"
导出

保存为 Markdown

wechat-cli export "示例群" --format markdown --output "example.md"

“张三”“示例群”是演示名称，运行时替换成你自己的联系人或群名。更多参数可运行 wechat-cli <命令> --help 查看。

GOOD TO KNOW

安装小贴士

从第一次运行，到日常更新。

反馈问题 ↗
提示找不到 wechat-cli 命令？

安装后重新打开终端再试。运行 npm prefix -g 查看全局安装目录，确认该目录在 Windows 的 PATH 中。也可以尝试别名 wechat-cli-local --help。

初始化时，如何指定微信数据库目录？

用 --db-dir 指定账号下的 db_storage 目录。下面是占位路径：

wechat-cli init --db-dir "D:\WeChatData\xwechat_files\wxid_example\db_storage"
如何更新或卸载？

更新到 npm 的最新发行版：

npm update -g wechat-cli-local

卸载 CLI：npm uninstall -g wechat-cli-local。

支持哪些平台？需要 Python 吗？

当前 npm 发行版面向 Windows x64，包含独立可执行程序，运行时需要 Node.js 22 或更新版本。Python 源码安装方式见 仓库文档。
