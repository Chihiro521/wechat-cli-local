03 / PRESS START

准备好？三步开始。

WINDOWS x64
01PREPARE

准备 Node.js

需要 Node.js 22 或更新版本。先检查本机版本：

node --version
npm --version

首次安装？前往 Node.js 官网下载 LTS ↗，安装后重新打开 PowerShell。

02INSTALL

安装 CLI

安装启动器与 Windows 独立程序，然后确认安装：

npm install -g wechat-cli-local
wechat-cli --version
wechat-cli --help

包名是 wechat-cli-local；wechat-cli 与 wechat-cli-local 两个命令都能使用。

03LET'S GO

初始化，开始查询

先启动并登录本机微信，再初始化读取配置：

wechat-cli init
wechat-cli sessions --limit 10

需要进程读取权限时，可在管理员 PowerShell 中执行。配置位于 ~/.wechat-cli/。

到 GitHub 反馈问题 ↗
01 提示找不到 wechat-cli 命令？

安装后重新打开终端再试。运行 npm prefix -g 查看全局安装目录，确认该目录在 Windows 的 PATH 中。也可以尝试别名 wechat-cli-local --help。

02 如何指定微信数据库目录？

用 --db-dir 指定账号下的 db_storage 目录。下面是占位路径：

wechat-cli init --db-dir "D:\WeChatData\xwechat_files\wxid_example\db_storage"
03 如何更新或卸载？

更新到 npm 的最新发行版：

npm update -g wechat-cli-local

卸载 CLI：npm uninstall -g wechat-cli-local。

04 支持哪些平台？需要 Python 吗？

当前 npm 发行版支持 Windows x64，包含独立可执行程序；运行时需要 Node.js 22 或更新版本，无需安装 Python。Python 源码安装方式见 仓库文档。

05 还能在哪里了解这个项目？

中文文档包含完整命令和构建说明；npm 页面提供发行版本；源代码与更新记录可以在 GitHub 仓库查看。
